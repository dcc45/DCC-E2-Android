# DCC Android redesign

This Android Studio project provides a modern Jetpack Compose redesign based on the original DCC and Dreambox Control Center screens.

## Open in Android Studio

Open `DCCAndroid` as an Android project and let Gradle sync. The app uses Kotlin, Jetpack Compose, and Material 3.

## Prototype scope

- Modern dashboard for the phone, Dreambox, and router
- Reconnect and network-search controls
- FTP and Telnet status cards
- Quick-tools area
- Bottom navigation

The connection actions currently show UI feedback only. FTP, Telnet, discovery, and receiver operations still need protocol implementation.
